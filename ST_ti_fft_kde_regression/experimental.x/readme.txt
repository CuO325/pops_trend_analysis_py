Hierarchical Student‑t Regression for Multi‑Site Trend Analysis
This script implements a hierarchical Bayesian regression model
to estimate site‑specific temporal trends in environmental or QSAR datasets.

Features
Site‑specific slopes and intercepts

Partial pooling via hierarchical priors

Robust Student‑t residuals

R‑hat convergence diagnostics

Posterior credible intervals

Half‑life estimation

OLS comparison

JSON and CSV summary outputs

Suitable for
Environmental monitoring

Water quality trend analysis

Multi‑site chemical concentration data

QSAR with hierarchical structure

Toxicology and exposure assessment
