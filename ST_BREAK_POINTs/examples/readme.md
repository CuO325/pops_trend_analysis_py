
# POPs Monitoring Trend Analysis: HCBD (Hexachlorobutadiene)

本レポートは、残留性有機汚染物質（POPs）である **ヘキサクロロブタジエン（HCBD）** のモニタリングデータに対し、古典的変化点分析（Classical Breakpoint Analysis）、STL分解、およびベイズ的変化点分析（Bayesian Breakpoint Analysis）を適用して傾向・構造変化を評価した結果をまとめたものです。

---

## 📌 概要・総合評価

- **推奨モデル**: **1-break モデル**（よりシンプルで頑健）
- **モデル選択理由**: 
  - WAIC判定において 1-break（Weight: 65.0%）と 2-break（Weight: 35.0%）の差は僅かです。
  - **堅牢性ペナルティスコア** では、1-break モデルが **`0.00`** に対し、2-break モデルは **`3.00`** と大きく劣化しています。
  - 統計モデルの基本原則（オッカムの剃刀）に基づき、過剰なパラメータ化を避け、代表線適合度および不確実性の少ない **1-break モデル** の採用を推奨します。

## 📝 考察・結論

1. **濃度変化の主要ポイント**:
   * 2016年から2017年9月頃にかけて上昇傾向がみられましたが、**2017年9月を境に減少・安定化**へと転じています。
2. **モデル採用の方針**:
   * 2-breakモデルは一見複雑な変動を説明できそうですが、データへの当てはまりが悪化し過学習の兆候（代表線適合不全・非線形ギャップ）が見られるため不適切です。
   * したがって、構造変化を1回と捉える **「1-break モデル（変化点: 2017年9月）」** を用いて傾向を評価するのが最も妥当です。

= POPs Monitoring Trend Analysis Report (PCB-Di) - 結論とロジック解説

== 結論（モデル採用に関する最終見解）

* **推奨モデル**: **1-break モデル**（変化点 1 箇所のシンプルなモデル）
* **判断の要旨**:
  WAIC（情報量規準）の数値上は 2-break モデルが優位と判定されるものの、過学習の兆候および多角的な堅牢性ペナルティを考慮すると、統計モデルの原則（オッカムの剃刀）に従い、よりシンプルで頑健な **1-break モデル** をベースに考察を進めることが推奨されます。

---

== 結論に至る論理と評価プロセス

=== 1. WAIC による形式的評価（2-break の見かけ上の優位性）
* **評価結果**:
  WAIC 判定では「2-break モデル」が 100.0% の確率で優位（WAIC: -375.02 vs 1-break: -292.56）と算出されました。
* **解釈**:
  単純なデータへの当てはまりや説明力のみを評価すると 2-break モデルが選ばれますが、WAIC はモデル選択の唯一の基準ではない点に注意が必要です。

=== 2. 堅牢性とモデル適合度の多角的な検証（2-break の課題）
多角的なペナルティ評価を行った結果、2-break モデルには以下の重大な過学習・不適合の懸念が確認されました。

1. **代表線適合度の悪化 (RMSE)**
   * 1-break: 0.1036 (pt: 0.00)
   * 2-break: **0.1387 (pt: 1.00)**
   * 事後分布の平均パラメータによる代表線フィット曲線において、2-break モデルの方がデータとの乖離が大きくなっています。

2. **大きな非線形ギャップ (Gap)**
   * 1-break: 0.0044 (pt: 0.00)
   * 2-break: **0.1126 (pt: 1.00)**
   * 事後予測平均 E[μ] と代表線 μ(E[θ]) の間に大きなギャップが生じており、過学習の兆候を示しています。

3. **熱力学的積分（TI: Thermodynamic Integration）の不全**
   * 周辺尤度の厳密計算において `tv_ratio2=1.12 Failed` となり、モデル比較に TI を活用できない状態（データへの根本的な適合不足）となっています。

=== 3. 総合評価とオッカムの剃刀による判断
* **ペナルティスコアの比較**:
  * **1-break モデル**: 総合ペナルティスコア **1.00**
  * **2-break モデル**: 総合ペナルティスコア **2.00**

WAIC では 2-break が優勢であるものの、堅牢性・パラメータ適合度において 2-break に大きな不確実性と乖離が見られるため、過剰なパラメータ化を避けてより実質的・物理的に安定した **1-break モデル** を採用するべきであるという論理展開になっています。
