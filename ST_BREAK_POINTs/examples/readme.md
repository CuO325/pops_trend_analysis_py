
# POPs Monitoring Trend Analysis: HCBD (Hexachlorobutadiene)

本レポートは、残留性有機汚染物質（POPs）である **ヘキサクロロブタジエン（HCBD）** のモニタリングデータに対し、古典的変化点分析（Classical Breakpoint Analysis）、STL分解、およびベイズ的変化点分析（Bayesian Breakpoint Analysis）を適用して傾向・構造変化を評価した結果をまとめたものです。

---

## 📌 概要・総合評価

- **推奨モデル**: **1-break モデル**（よりシンプルで頑健）
- **モデル選択理由**: 
  - WAIC判定において 1-break（Weight: 65.0%）と 2-break（Weight: 35.0%）の差は僅かです。
  - **堅牢性ペナルティスコア** では、1-break モデルが **`0.00`** に対し、2-break モデルは **`3.00`** と大きく劣化しています。
  - 統計モデルの基本原則（オッカムの剃刀）に基づき、過剰なパラメータ化を避け、代表線適合度および不確実性の少ない **1-break モデル** の採用を推奨します。

---

## ⚖️ WAIC & ベイズモデル比較 (Bayesian Breakpoint)

### 1. WAIC 評価
* **1-break model**: Weight **65.0%** / WAIC `-216.05`
* **2-break model**: Weight **35.0%** / WAIC `-214.81`

### 2. 推定変化点 (95% 信用区間)
* **1-break モデル**:
  * $\tau_1$: **2017年09月** (95% CI: 2017-08 〜 2017-10)
* **2-break モデル**:
  * $\tau_1$: **2016年03月** (95% CI: 2016-01 〜 2016-08)
  * $\tau_2$: **2017年09月** (95% CI: 2017-08 〜 2017-10)

## 📝 考察・結論

1. **濃度変化の主要ポイント**:
   * 2016年から2017年9月頃にかけて上昇傾向がみられましたが、**2017年9月を境に減少・安定化**へと転じています。
2. **モデル採用の方針**:
   * 2-breakモデルは一見複雑な変動を説明できそうですが、データへの当てはまりが悪化し過学習の兆候（代表線適合不全・非線形ギャップ）が見られるため不適切です。
   * したがって、構造変化を1回と捉える **「1-break モデル（変化点: 2017年9月）」** を用いて傾向を評価するのが最も妥当です。
